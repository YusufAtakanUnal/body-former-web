# App screenshots

Drop your in-app screenshots here with these exact filenames. They will appear
automatically in the website (Hero, Digital Twin, and App Showcase sections).
Until a file exists, a labelled placeholder is shown in its place.

| Filename            | Where it shows                          |
| ------------------- | --------------------------------------- |
| `today.png`         | Hero phone + Showcase                   |
| `measurements.png`  | Digital Twin (left phone) + Showcase    |
| `bodyfat.png`       | Digital Twin (right phone) + Showcase   |
| `ranks.png`         | Showcase                                |

## Tips

- **Aspect ratio:** the frames expect a tall phone screenshot (~9:19.5).
  Full-screen phone captures work perfectly.
- **Format:** PNG or JPG. Keep each file reasonably sized (< 1–2 MB ideally).
- You can add more later — extend the `shots` array in
  `src/components/Sections.tsx` (Showcase) to reference new files.
